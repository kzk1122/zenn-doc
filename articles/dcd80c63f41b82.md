## はじめに

Claudeの勉強を兼ねて設計レビューの指摘一覧から品質傾向を可視化し分析の補助となるツールのプロトタイプを作りました。
分析についてはClaudeを使ってAIによる分析を行うようにしています。
また、Claude.aiのアーティファクト機能を使うことで、サーバーなしでブラウザ上だけで完結します。
下記デモ用リンクから実際に動かすことが可能です（Claude.aiへのログインが必要です）。

https://claude.ai/public/artifacts/defd6a58-f889-46df-a490-f5b7987789b9

## ツールについて

### 概要

Excelのレビュー指摘一覧をドラッグ＆ドロップするだけで、以下を自動生成します。

- **8種類のダッシュボードタブ**による多角的な集計・可視化
- **Claude APIを使ったAI分析**による改善策提案・担当者評価

### ダッシュボード（8タブ）

| タブ | 内容 |
|------|------|
| 概要 | 総指摘件数・最多分類・原因のサマリーカード＋円グラフ |
| 指摘一覧 | 全指摘のカード表示。キーワード検索・各種フィルタリング・ページネーション対応 |
| 不具合分類 | 分類別の横棒グラフ＋パレート表（件数・割合・累積割合） |
| 原因分析 | 原因分布の棒グラフ＋レーダーチャート |
| 混入工程 | 工程別の円グラフ・棒グラフ＋クロス集計 |
| ドキュメント別 | 文書別指摘件数＋クロス集計 |
| 担当者別 | 担当者別件数・クロス集計＋AI担当者評価 |
| AI分析・改善策 | 全体傾向の分析と具体的な改善策提案 |

### AI分析機能

Claude APIと連携した分析が2種類あります。

**全体分析**：不具合分類・原因・ドキュメント別の傾向から、チーム全体への改善策を提案します。カスタムプロンプトで分析観点を追加指定することも可能です。

**担当者評価**：担当者ごとの指摘傾向を分析し、強み・課題・改善アクションをカード形式で表示します。リスクレベルのバッジも付くので、フォローが必要なメンバーを一目で把握できます。

### このツールで実現できること

- **原因部類などの可視化**：「なんとなくこの指摘が多い気がする」を数値とグラフで確認できる
- **担当者ごとの傾向把握**：フォローが必要なメンバーを早期に特定できる
- **AI による改善策提案**：集計データを渡すだけで、具体的なアクションをClaudeが提案してくれる

## 技術スタック

| 技術 | 用途 |
|------|------|
| React | UIフレームワーク（Claude.aiアーティファクトとして動作） |
| Recharts | グラフ描画（円グラフ、棒グラフ、レーダーチャート） |
| SheetJS (xlsx) | Excelファイルの読み込み・列名の自動認識 |
| Claude API | AI分析・担当者評価（claude-sonnet-4） |

単一の `.jsx` ファイルで完結しており、ビルド不要です。Claude.aiのアーティファクト機能の上で動作するため、サーバーもDBも不要です。

## 使い方

### 1. アーティファクトを開く

下記URLにアクセスします（Claude.aiへのログインが必要です）。

https://claude.ai/public/artifacts/defd6a58-f889-46df-a490-f5b7987789b9

### 2. Excelをアップロードする

以下の列を含むExcelファイルを用意し、ドラッグ＆ドロップします。

| 列 | 必須/任意 | 例 |
|----|----------|----|
| 不具合分類 | 必須 | 内容漏れ、内容誤り、規約違反 |
| 不具合原因 | 必須 | 業務習熟不足、不注意、検討不十分 |
| 指摘内容 | 必須 | 自由記述テキスト |
| ドキュメント名 | 必須 | 認証機能 詳細設計書 |
| 担当者 | 任意 | 担当者別タブ・AI評価で使用 |
| 混入工程 | 任意 | 混入工程タブで使用 |

列名は完全一致でなくても自動認識されます。

### 3. ダッシュボードを確認する

自動的に集計・グラフ化されます。各タブを切り替えて分析を確認し、必要に応じてAI分析を実行します。

### サンプルファイルで試す

下記リポジトリの `doc/sample/` に動作確認用サンプルを3種類用意しています。
https://github.com/kzk1122/ReviewQualityAnalyzer

| ファイル | 内容 |
|----------|------|
| レビュー指摘一覧_サンプル_担当者集中パターン.xlsx | 特定担当者に指摘が集中したケース（43件） |
| レビュー指摘一覧_サンプル_内容漏れ集中パターン.xlsx | 「内容漏れ」が約65%を占めるケース（43件） |
| レビュー指摘一覧_サンプル_100件.xlsx | 汎用的なサンプル（100件） |

## まとめ
Claudeの勉強がてら思いついたアイディアをClaudeと対話しながら修正を重ね作りましたが、自分でコードを書かずにそれなりに良さそうなものが実現できたのは驚きました。
改善を重ねた結果今の形になるのにトータルで5、6時間かかりましたが、最初のアウトプットは30分かからずできたのでAIを使ってアイディアをすぐ形にできるのは便利だと感じました。
